# 03_isometric — 아이소메트릭 2.5D

## 표현 방식
- **Canvas 2D 직접 렌더링**, 2:1 아이소메트릭 투영 `sx = (x − y)·u`, `sy = (x + y)·u/2 − z·u·1.2`.
- 바닥 그리드(1칸/5칸 강조) 위에 **U자 컨베이어**(기본) 또는 **직선 컨베이어**(상단 "레이아웃"에서 전환)를 자동 배치합니다. U자는 앞쪽 절반 공정을 위쪽 열에, 나머지를 아래쪽 열(역방향)에 둡니다.
- 셀마다 다음을 그립니다.
  - `palletSlots` 개수의 지그 슬롯 박스. 윗면 테두리 색이 슬롯 상태입니다.
  - `testPcs` 개수의 PC 랙과 모니터. 모니터 화면 색이 idle/busy/pass/fail이고, busy일 때는 진행률 바가 표시됩니다.
  - PC와 담당 슬롯을 잇는 바닥 케이블선, NG 배출함, 단계 번호·코드·이름 라벨.
- 팔레트(나무 팔레트 위에 AVN 본체)는 컨베이어를 따라 이동하고, 앞이 막히면 줄을 서서 대기합니다(노란색). 이후 빈 슬롯으로 횡이송되고, 검사가 끝나면 다음 공정으로 나갑니다. 최종 불합격품은 NG함으로 빠집니다.
- 박스는 중심 `x+y` 기준 화가 알고리즘(painter's algorithm)으로 깊이 정렬합니다. 컨베이어는 1칸 단위 청크로 쪼개 겹침 오류를 줄였습니다.
- 셀에 마우스를 올리면 단계 상세 툴팁이 뜹니다. 사이클 타임, 불량률, 슬롯·PC 사용 현황, 이론 능력, 대기열, 검사·통과·Fail·재검사·NG 수, 가동률, 검사 항목을 보여줍니다.
- 하단 KPI: 시뮬레이션 시간, 투입, 양품, NG, 재검사, 수율/FPY, UPH(최근 1시간·누적·목표), WIP, 평균 리드타임, 병목 공정. 공정별 가동률 바도 함께 표시합니다.
- 컨트롤: 재생/일시정지(Space), 배속(기본값 `simulation.speed`), 초기화, 레이아웃 전환, 화면 맞춤. 휠로 확대/축소, 드래그로 이동, 더블클릭으로 화면에 맞춥니다.

### 시뮬레이션 모델
- 고정 스텝(0.025 sim초)과 `randomSeed` 기반 mulberry32 난수를 씁니다. 그래서 배속을 바꿔도 결과가 같고, 초기화하면 처음부터 똑같이 재현됩니다. 레이아웃을 바꾸면 이송 거리가 달라지므로 결과도 달라집니다.
- `palletCount`는 라인 안을 순환하는 팔레트 수(WIP 상한)로 해석했습니다. `arrivalIntervalSec`마다 1대씩 투입하며, 팔레트 풀이 비었거나 입구가 막히면 투입이 대기합니다.
- 컨베이어 속도는 `경로 길이 / (단계 수 + 1) / conveyorTransferSec`입니다. 즉 공정 사이 평균 이동 시간이 `conveyorTransferSec`가 됩니다.
- 슬롯은 PC에 연속 구간으로 나눠 배정합니다(예: 슬롯 4, PC 2이면 PC1에 S1–S2, PC2에 S3–S4). 검사 시간은 `cycleTimeSec × (0.9~1.1)`입니다.
- 첫 검사는 `failRate` 확률로 Fail입니다. `retestOnFail`이면 `maxRetest`회까지 같은 슬롯에서 재검사합니다. 재검사 때 다시 불합격할 확률은 데이터에 `simulation.retestFailProb`가 있으면 그 값을, 없으면 모델 가정값 0.3을 씁니다. 재검사 한도를 넘으면 NG 처리합니다.
- 다음 공정의 컨베이어 버퍼(셀 간격으로 자동 계산, 1~4대)가 가득 차면 검사를 마친 팔레트가 슬롯에 남아 "대기/정체" 색으로 바뀝니다(블로킹).

## 장점
1. 공간감이 있어서 실제 라인 배치(슬롯·PC 랙·컨베이어 흐름)를 현장 사람이 직관적으로 알아봅니다.
2. 라이브러리 없이 HTML·CSS·JS 3개 파일뿐이고, file://로 바로 열리며 가볍습니다.
3. 데이터만으로 셀 크기와 배치가 정해지므로 단계 수나 슬롯·PC 수가 바뀌어도 자동으로 다시 배치됩니다.

## 단점
1. 화가 알고리즘 기반이라 물체가 크거나 겹치면 깊이 정렬이 어긋날 수 있습니다. 회전 시점도 지원하지 않습니다.
2. 단계가 많거나 직선 레이아웃이면 기본 배율이 작아집니다. 확대/이동이 필요하고, 라벨이 서로 겹칠 수 있습니다.
3. 수치 비교(추세, 시간축)에는 약해서 차트형 대시보드보다 정량 분석이 불편합니다.

## 사용 라이브러리 / 라이선스
- 없음. 순수 HTML/CSS/JavaScript(Canvas 2D API)입니다. 외부 폰트·CDN·네트워크 요청도 없습니다(시스템 폰트 사용).
- 의사난수 mulberry32는 퍼블릭 도메인 알고리즘을 직접 구현했습니다.

## 데이터 수정 방법
1. `../data/line.json`을 수정합니다. 단계 추가·삭제, `palletSlots`, `testPcs`, `cycleTimeSec`, `failRate`, `simulation.*`, `statusColors` 등을 바꿀 수 있습니다.
2. `sh ../data/sync.sh`를 실행해 `line.js`를 다시 생성합니다. file://에서는 fetch가 막혀 `line.js`(`window.LINE_DATA`)를 읽습니다.
3. `index.html`을 새로고침하면 반영됩니다.
- 선택 항목: `simulation.retestFailProb`(재검사 시 재불량 확률, 기본 0.3)를 추가하면 그 값을 씁니다.
- 디버그: 브라우저 콘솔에서 `__isoSim.run(3600)`(1시간 즉시 진행), `__isoSim.state()`로 상태를 확인할 수 있습니다.
