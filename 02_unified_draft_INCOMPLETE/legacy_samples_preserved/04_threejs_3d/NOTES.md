# AVN 3D 검사 라인

## 표현 방식
- 공통 LINE_DATA의 모든 단계를 일렬 배치하고, 슬롯은 납작한 지그, PC는 타워와 발광 모니터로 표현한다.
- 팔레트는 컨베이어 → 예약 슬롯 → PC 검사 → 다음 단계로 이동하며, 재검 한도 초과 불량은 빨간 리젝트 레인으로 배출한다.
- 초기 시점은 빈 라인이며 시뮬레이션 시간으로 투입한다. 0.05초 고정 스텝과 randomSeed 난수로 검사 결과를 재현한다.

## 장점 (3줄)
- 서버, 인터넷, 모듈 없이 index.html을 file://로 직접 열 수 있다.
- 라벨 포함 바운딩 박스 자동 맞춤과 40도 내려보기, 드래그 회전 및 휠 줌을 지원한다.
- 통과·불량은 배출 완료 시 집계하며 UPH는 통과수/시뮬 경과초×3600, 경과 0초는 —로 표시한다.

## 한계 (3줄)
- 실제 PLC나 MES를 연결하지 않은 가상 공정이며, 기구 형상과 물류 간섭은 단순화했다.
- 단계 수가 크게 늘거나 창이 좁으면 전체 보기에서 글씨가 작아지므로 휠 줌으로 확대해야 한다.
- palletCount는 동시 운용 팔레트 상한이며, 화면이 백그라운드일 때 현실 시계와 시뮬 시간이 달라질 수 있다.

## 라이브러리 및 라이선스
Three.js r159 UMD: ./vendor/three/three.min.js, MIT (전문: ./vendor/three/LICENSE).
OrbitControls, 외부 폰트, CDN 및 추가 라이브러리는 사용하지 않는다. UI와 시뮬레이션은 app.js 클래식 스크립트이다.

## 데이터 수정 방법
공통 원본은 ../data/line.json이다. 원본 변경 후 데이터 관리자가 ../data/sync.sh를 실행해 ../data/line.js를 동기화하고 페이지를 다시 연다.
이 작업에서는 공통 data 폴더를 수정하지 않았다. 단계 수·이름·슬롯·PC·검사시간·불량률·시뮬레이션·상태색은 모두 window.LINE_DATA에서 읽는다.
재생/일시정지, 배속 변경, 전체 보기 버튼을 제공하며 초기 배속은 simulation.speed 그대로이다.

## 검증
- node --check app.js 통과.
- ego-browser에서 file:// 로딩, 팔레트 투입과 첫 검사 상태, 확대된 라벨을 시각 확인했다.
- 50배속으로 첫 최종 통과까지 실행: 시뮬 9분 16초에 통과 1 / 불량 0 / UPH 6.5, 일시정지 버튼 반영 확인.
- 브라우저 자동 실행은 기본 샌드박스의 macOS 앱 연결 제한으로 실패하여 승인된 샌드박스 밖 실행을 사용했다. 서버나 포트를 열지 않았다.
- 브라우저 콘솔 이벤트 전체 수집 및 모든 불량 분기의 시각 검증은 수행하지 않았다.
- Ego Lite 업데이트 알림이 있었으나 설치·업그레이드는 수행하지 않았다.
