# AVN 검사라인 2D 탑다운

## 표현 방식
`index.html`의 SVG/CSS 도면과 `app.js`의 클래식 IIFE 시뮬레이션으로 구성했습니다. 공정 카드에 데이터의 슬롯 및 PC 수를 그리며, 팔레트가 공정 사이를 이동하고 불량은 빨간색으로 리젝트 레인에 표시됩니다. KPI에서 통과·불량 누계와 시뮬레이션 UPH를 확인하고 재생·일시정지와 배속을 조절할 수 있습니다.

## 장점
- `../data/line.js`의 `window.LINE_DATA`에서 공정명, 단계, 슬롯·PC, 검사시간, 불량률과 색상 설정을 읽습니다.
- 공정 수에 맞춰 카드 위치를 계산하며 팔레트 시드는 재현 가능합니다.
- 외부 URL이나 라이브러리 없이 `file://`에서 실행됩니다.

## 단점
- 공정이 많이 늘면 한 화면의 공정 카드가 작아집니다.
- 설비 제어가 아닌 시각화용 가상 시뮬레이션입니다.
- 누적 수치는 검사 이벤트 기준이며 실제 생산 데이터와 연결되지 않습니다.

## 사용 라이브러리 / 라이선스
브라우저 내장 HTML, CSS, SVG, JavaScript만 사용했습니다. 외부 라이브러리 없음.

## 데이터 수정 방법
`../data/line.json`을 수정한 뒤 데이터 폴더의 `sync.sh`로 `line.js`를 갱신합니다. 이 샘플에서는 공통 데이터 파일을 수정하지 않습니다.

## 시뮬레이션 수치 및 팔레트 표시
UPH는 최종 공정에서 완료된 통과 대수를 누적 시뮬레이션 시간(초)으로 나누어 시간당으로 환산합니다. 스테이션별 통과·불량 횟수를 표시하며 리젝트 칸은 불량 팔레트가 발생할 때만 빨간색으로 점유됩니다.
